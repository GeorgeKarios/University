## Large files

Files larger than 100 MB are distributed through the [University files release](https://github.com/GeorgeKarios/University/releases/tag/university-files-2026-10-09). Their original paths and SHA-256 checksums are recorded in `upload-manifest.json`.

After downloading or cloning this repository, run `python restore-large-files.py` from its root to download those files into their original locations. Python 3.9 or later is required. The script verifies downloads and does not replace an existing different file.
